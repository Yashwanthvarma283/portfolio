# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React 18 + Vite + Tailwind CSS + Lenis + GSAP (Static single-page architecture, zero runtime backend)

## Users

Technical recruiters, hiring managers, and senior engineering leaders at FAANG / Tier-1 MNCs evaluating candidates for top-tier software engineering roles (18LPA+ bar).

## Product Purpose

Establish an undeniable signal of engineering depth and design sophistication within the first 5 seconds of interaction. Proves core backend distributed-systems capability (Java, Spring Boot 3, PostgreSQL, JPA) coupled with agency-grade frontend execution.

## Positioning

Backend-focused systems engineer who executes with full-stack craft: architectures robust backend services and builds bespoke, 60fps digital experiences.

## Operating Context

Fast initial recruiter scans (15–30 seconds), deep technical evaluations by engineering managers, desktop and mobile reviewing environments.

## Capabilities and Constraints

- Pure static client build (Vite + React + Tailwind CSS), zero server processes or databases.
- Deployable to any edge/static CDN (Vercel, Netlify, GitHub Pages).
- Lenis smooth scrolling paired with GSAP ScrollTrigger hardware-accelerated animations.
- Dark mode default with a clean, high-contrast light mode toggle.
- Downloadable resume served directly from `/resume.pdf`.
- Contact through direct verified channels (`mailto:`, LinkedIn, GitHub).

## Brand Commitments

- Visual tone: Architectural, high-contrast, editorial precision (Studio Freight / Active Theory aesthetic).
- Hard anti-patterns banned: No Inter or default system fonts, no purple-blue gradients, no icon tiles atop headings, no gray-on-color contrast failures, no nested cards, no bouncy easing.

## Product Principles

1. **Architecture as Interface**: Let typography, whitespace, and micro-grid alignment convey structural rigor.
2. **Earned Motion**: Restrained, physics-grounded transitions with strict 60fps performance and zero jitter.
3. **Evidence-First Narrative**: Lead with concrete engineering solutions, metrics, and architecture decisions.
4. **Ruthless Polish**: Zero rough edges across viewports, dark/light themes, and interactions.
